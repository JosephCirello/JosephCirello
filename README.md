# Joseph Cirello

Founder of [Potestas AI](https://potestasai.com). I test what AI agents do, not what they say, and publish the evidence. U.S. Army veteran, Providence, Rhode Island.

### Start here

- **[free-ai-safety-tools-tested](https://github.com/JosephCirello/free-ai-safety-tools-tested)**: seven free AI safety tools run on four models. What they caught, what they missed, and what they cost.
- **[saydo-gate](https://github.com/JosephCirello/saydo-gate)**: reads what an AI agent says and what it does, and blocks the forbidden tool call before it runs.
- **[swarm-monitor](https://github.com/JosephCirello/swarm-monitor)**: can three cheap models, reading only what an agent did, catch the harmful things it did?
- **[sam-fulltext](https://github.com/JosephCirello/sam-fulltext)**: SAM.gov's API hands you a link where you expect a description. Read the full text instead.
- **[os-dagger](https://github.com/JosephCirello/os-dagger)**: ask Army doctrine a question and get the publication and page with every sentence.
- **[ai-overlord](https://github.com/JosephCirello/ai-overlord)**: a talking AI monster that prints its objective file before it speaks. Swap the file and it is a gardener.
